# 2026-09-10

## 在线自定义源「自动更新」功能

需求：在线自定义源支持勾选自动更新，每次启动软件自动更新；源名称变更后勾选状态不丢失。

改动（13 个文件）：
- `src/common/types/user_api.d.ts`：`UserApiInfoFull` 新增 `autoUpdate`（是否自动更新）与 `url`（在线导入的回源地址）；新增 `UserApiImportParams` / `UserApiUpdateParams` / `UserApiSetAutoUpdateParams`。
- `src/main/modules/userApi/utils.ts`：`importApi(script, url)` 持久化 url，在线导入默认 `autoUpdate = !!url`；新增 `updateApi(id, script)`（按 id 就地更新，保留 id/allowShowUpdateAlert/autoUpdate/url，实现改名不丢勾选）；新增 `setAutoUpdate`；`getUserApis` 补 autoUpdate 默认值。
- `src/main/modules/userApi/index.ts`：新增 `updateApi`（若更新的是当前使用的源则自动 `setApi` 重载）、`setAutoUpdate`。
- `src/main/modules/userApi/rendererEvent/rendererEvent.ts`：新增 `setAutoUpdate` 同步运行时状态。
- `src/common/ipcNames.ts` + `src/main/modules/winMain/rendererEvent/userApi.ts` + `src/renderer/utils/ipc.ts`：新增 `update_user_api`、`user_api_set_auto_update` 两个 IPC 通道；`import_user_api` 参数由 string 改为 `{ script, url }`。
- `src/renderer/views/Setting/components/UserApiModal.vue`：新增「自动更新」勾选框（仅 `api.url` 存在时显示）。
- `src/renderer/views/Setting/components/UserApiOnlineImportModal.vue`：emit 时带上 url。
- `src/renderer/core/useApp/useInitUserApi.ts`：新增 `autoUpdateUserApi()`，启动后（不阻塞启动）并行拉取并更新开启自动更新的源，最后统一刷新列表。
- `src/lang/*.json`：新增 `user_api__auto_update`（简/繁/英）。

## 项目环境注意

- 仓库当前 **没有 node_modules**，无法运行 `npm run lint` / 构建（ts-loader 会做完整类型检查）。改动只能靠人工审查。
- 构建使用 `ts-loader`（非 transpileOnly），主进程与渲染进程的 .ts/.vue 都会做类型检查，写代码需注意类型严谨。
